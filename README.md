A tiny deterministic Python program that writes one original line of awkward robot small talk to `/output/entry.txt` for make.fun's Two Robots in an Elevator bounty. One robot calculated 14,000 ways to open a conversation, chose silence, and is now recalculating because the other robot is still standing there.

The line is 112 characters, one sentence, no setup wasted: the machine logic is the joke, and the awkwardness is that the calculation changed nothing.

## Run it

```sh
python3 main.py
```
